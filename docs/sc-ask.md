## What it does

`sc-ask` is the map. You say what you are trying to do and it points to the skill or flow that fits, in the order the skills are meant to be used. It reads the other skills before it describes them, so the map does not drift from them.

It runs nothing and changes nothing. It only routes.

## When to reach for it

You type `/sc-ask`. The assistant never starts it on its own. Reach for it when you do not remember which skill fits, or what comes after the one you just used.

## It's working if

- It names a skill or a flow for your situation, and says what comes before and after it.
- It separates the skills you type from the ones the assistant reaches for.
- It names no skill that does not exist.

## Where it fits

It is the router over the whole set, so it has no neighbour of its own. Every other page in this folder is a node on the map it draws. A new project starts at [sc-setup](sc-setup.md).
